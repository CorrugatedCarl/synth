### 3.8 Unison (`UNI_STACKS`, `UNI_MODES`)

| idx | stack label | semitone offset of unison voice i (voices sorted by detune slot, i = 0…N−1) |
|---|---|---|
| 0 | `off` | 0 |
| 1 | `12 (1x)` | i odd → +12 |
| 2 | `12 (2x)` | i odd → 12·(1 + ((i−1)/2 mod 2)) → 0, 12, 0, 24, 0, 12, … |
| 3 | `12 (3x)` | i odd → 12·(1 + ((i−1)/2 mod 3)) |
| 4 | `12+7(1x)` | cycle `[0, 7, 12]` by i |
| 5 | `12+7(2x)` | cycle `[0, 7, 12, 19, 24]` |
| 6 | `12+7(3x)` | cycle `[0, 7, 12, 19, 24, 31, 36]` |
| 7 | `Center-12` | centre voice(s) −12 (odd N: i = (N−1)/2; even N: i = N/2−1 and N/2) |
| 8 | `Center-24` | centre voice(s) −24 |

| idx | mode | detune slot shape `s(t)`, slot `t_i = N>1 ? 2i/(N−1) − 1 : 0` |
|---|---|---|
| 0 | `Linear` | `t` |
| 1 | `Super` | `sign(t)·|t|^1.5` |
| 2 | `Exp.` | `sign(t)·|t|^2.5` |
| 3 | `Inv.` | `sign(t)·|t|^0.5` |
| 4 | `Random` | uniform in [−1, 1], drawn per unison voice at every note-on (centre voice(s) included) |

Detune of unison voice i (semitones) = `s(t_i) · d · R/2`, d = `det` engine value (0…1), R = `global.uniRange` (inv A4: total outer spread = R at d = 1).
Pan position = `t_i · width` (width = `uniw` value). Blend gains: centre voice(s) `g_c`, others `g_s`: b ≤ 0.75 → `g_c = 1, g_s = b/0.75`; b > 0.75 → `g_s = 1, g_c = (1−b)/0.25`. N = 1: g = 1; N = 2: both voices are "centre" (g_c) — BLEND inactive for N ≤ 2 (inv A3). Gain compensation: whole unison sum × `1/√(Σ g_i²)` (N = 1 → 1).
WT position offset of voice i = `t_i · uniwt · 0.5` (in table-position units n, i.e. ±half table at ±100 %); warp offset = `t_i · uniwarp · 0.5`; both added to the eff value then clamped to [0,1].

### 3.13 Destinations (`DESTS`, `DEST_INDEX`, `NS = 119`, `NF = 86`, `ND = 205`)

Two segments:
- **SYNTH** (idx 0–118): base values in `s.p`, delivered in `CP.base` (Float64Array(119), index = idx). Consumed by voices; rows with V*M scope are additionally evaluated in the mono context (§5.5).
- **FX** (idx 119–204, *fx idx* = idx − 119): base values in `fx.p` (except `g.master`, which lives in `s.p` and reaches `compileFx` through `ctx.master`); delivered in `FXP.base` (Float64Array(86), index = fx idx). Consumed once per processor by `FXRack`.

Columns: **law/lo/hi** per §3.1 (lo/hi in engine units); **def n** = default base; **fmt** per §3.2; **scope**: `V` per voice (evaluated every chunk), `V*` per voice but drives a source (one-chunk lag, §5.6; `uni` count sampled at note-on only), `V*M` per voice and also mono-evaluated for global consumers (Off-mode LFOs, mono chaos), `M` mono only (FX segment); **ctr** `C` = centred control → drag-and-drop default is bipolar (inv A16.1).

Deliberate default choices where the sources conflict: `fx.cmp.mix` = 100 % (P1 says 50 % [low]); Reverb type Hall; reverb slot defaults from P1 (t .12, c .28, w 1.0); ENV 2/3 time defaults equal ENV 1 (A 0.11, H 0, D 0.5, R 0.215) with sustain 100 %.

Not destinations (deliberate, inv A16.5): enum menus other than Uni Stack (warp mode, filter type, distortion mode, delay/EQ/reverb types), switches other than the 10 FX enables, Mod Wheel / Pitch Bend / Bypass params (performance controls), macros (S1), matrix amounts, unison Range/Tuning, A4, oversampling.
