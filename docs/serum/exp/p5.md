#### 8.4.3 `SerumVoice`
```
new SerumVoice(proc, i)              // allocates all per-voice buffers for 16 unison voices × 2 oscs, filter, envs, LFOs
fields: active, gate, note, stamp, sus, det (= 0), vel           // engine-visible (ARCH)
apply(p)                             // patch changed: re-read p.serum; never resets sounding state; resolves table ids lazily
noteOn(n, vel01, legato, glc)        // §6.1
noteOff(rv)                          // §6.2 (rv optional release velocity 0–1)
kill()                               // §6.2
render(bufL, bufR, N, dirL, dirR)    // ADDS N OS-rate samples (N multiple of proc.CH); dirL/dirR only when CP.direct
```
CPU budget (normative target, node, M-class laptop): 8 voices × unison 16 × 2 oscillators (no warp), filter MG Low 24, at base 48 kHz × OS 2 renders 1 s of audio in ≤ 0.6 s; idle voices cost nothing; `begin` + `fxMods` ≤ 2 % of that.

#### 8.4.4 Snapshot / monitor
The engine posts `{t:'smon', ...snapshot}` at ≤ 30 Hz while a UI has asked for it (§11). Arrays are copied (not transferred).

#### 8.4.5 `SFilter` (standalone; also used by fx-dsp's Filter module)
```
new SFilter(fs)
setRate(fs)                          // recompute rate-dependent constants
setType(t)                           // 0–95; switching family resets state; same family keeps state
set(fcL, fcR, res, drive, vr)        // Hz, Hz, 0–1, 0–1, 0–1; cheap enough to call per sample
tick(xl, xr)                         // one stereo sample → this.yl, this.yr
process(L, R, n)                     // in place on Float64Array, current params
reset()
```
Behaviour per family/type: §3.4 + §6.11 (drive gain, EQ gain law, Var mapping, `f_var`, HL width). `set` clamps fc to [8, 0.45·fs]. Internal sample-rate-dependent delays (comb/bank/reverb families) are sized for the maximum delay at 8 Hz and allocated in the constructor/`setRate`.

#### 8.5.2 `FXRack`
```
new FXRack(base)                     // base = context sample rate; allocates every module's buffers (max delay 2 s per line at base)
set(fxp)                             // apply compiled FXP (any time; smooth); first call snaps; module enable 0→1 resets that module's state
setMods(offsets | null)              // Float64Array(86) of normalised offsets (fx idx); copied; reached linearly across the next process()
process(L, R, n, dL?, dR?)           // in place, Float64Array, n ≤ 128 base frames; modules in fxp.order; then + dL/dR; then × master
trigger()                            // a note-on happened (Hyper RETRIG)
reset()                              // clear every delay line / state (panic, transport stop with "silence tails")
idle() → boolean                     // true when no module is effectively enabled, or every enabled module's output stayed < 1e-6 for ≥ 1 s with zero input
monitor() → Float32Array(4)          // [single-band GR dB (≥ 0), MB low GR, MB mid GR, MB high GR] (multiband: GR may be negative = upward gain)
phases() → Float64Array(4)           // current LFO phases [hyper, flg, phs, cho] (host saves them into fx.phase on preset/project save)
latency                              // samples of look-ahead (Compressor Limit mode), else 0
```
- **Effective values**: per span, `eff = clamp(baseSmoothed + mod, 0, 1)` → law (§3.1) → engine value. Module enabled ⇔ eff `fx.<m>.on` ≥ 0.5 **and** `byp[m] = 0`. Enable/disable crossfades the module's output with its input over 5 ms; after a disable fade the module stops and resets (tail cut, as Serum).
- **Bypass-cheap**: when no module is enabled, `dL` is absent and master gain = 1 ± 1e-9, `process` returns after O(1) work and leaves L/R bit-identical.
- **Mix law** (inv A20.2): `out = in·(1 − m²) + wet·sin²(π·m/2)`; LEVEL trim gain `(2n)²` after the mix (`fx.<m>.level`). EQ: no mix/level. Hyper and Dimension are additive: `out = in + m·wet` (their MIX scales the added signal).
- Master stage: `× g.master` value (pow3; base from `ctx.master`) ramped per sample.
- Denormal flushing on every feedback state once per call.

#### 8.5.3 Module recipes (normative where tested in §10.5; otherwise IMPL-free within the stated character)
| Module | Recipe |
|---|---|
| Hyper | N = unison (0 = Hyper off). Voice j: delay line read at `d_j = 1.5 + 2.2·j ms + depth_j(t)`, `depth_j = detune·3 ms·(0.5 + 0.5·sin(2π·f_j·t + θ_j))`, `f_j = rateHz·(0.83 + 0.11·j)`, `rateHz = 0.1 + 6·rate²`; voices panned alternately (±(0.3 + 0.1·j)); wet = Σ voices·(1/√N); RETRIG: `trigger()` sets all θ_j = 0 and phases to 0 (unison "laser" start); LFO phases initialised from `fxp.phase[0]`. Measured target: at mix 1, +2.5 dB ± 1.5 dB total on a saw, side ≈ −4.5 dB. |
| Dimension | 4 lines at `T_k = (0.3 + 1.7·size)·[7.3, 11.9, 17.1, 23.3] ms` fed with mono `(L+R)/2`, each with AM `1 + 0.3·sin(2π·[0.13,0.17,0.23,0.29]·t)`; `side = (l0 − l1 + l2 − l3)/2`; `L += mix·side·0.45`, `R −= mix·side·0.45` (mid untouched; side ≈ −10 dB at mix 0.5) |
| Distortion | pre-filter (OFF/PRE/POST) TPT SVF at `F = fx.dist.freq`, `Q = 0.5·16^q`, output `lbh ≤ 0.5 ? lerp(lp, bp, 2·lbh) : lerp(bp, hp, 2·lbh − 1)`; shaper per §8.5.4; DC blocker (5 Hz) after asymmetric modes (0, 3, 9, 10, 12, 14); mix/level. Shaper runs at 2× (polyphase half-band up/down, 31 taps) for all modes except Downsample. |
| Flanger | per channel delay `d = 0.25 + 15.75·depth·(0.5 − 0.5·cos 2πφ) ms`, φ_R = φ_L + phase/360; feedback `0.95·feed` (positive) from the delay output into the line; `wet = 0.5·(in + delayed)`; rate Hz (`pow4` 0–20) or MODFX ladder |
| Phaser | 6 first-order allpasses per channel, corner `f = freq·2^(depth·4·(0.5 − 0.5·cos 2πφ) − depth·2)` (± 2 oct sweep at depth 1), feedback `0.95·feed` from the chain output; `wet = 0.5·(in + chain)` |
| Chorus | 4 taps: L1/L2/R1/R2 with base `dly1` (L1, R1) and `dly2` (L2, R2), modulation `depth·(0.5 + 0.5·sin(2πφ + θ))`, θ = 0, π, π/2, 3π/2 (mono flag: R taps use L's θ); minimum read delay 0.1 ms; feedback `feed` (value 0–0.95) from each tap into its own line; wet = `(L1+L2)/2`, `(R1+R2)/2` through a 2-pole LP at `lpf` |
| Delay | lines L/R up to 2 s; time `T = bpm ? beats(DLY_LADDER[round(n·11)])·60/bpm : (1 + 500n⁴) ms`, × offset; LINK: R uses L's time and offset; band filter in the feedback path *and* on the wet: HP at `F·2^(−bw/2)`, LP at `F·2^(+bw/2)` (2-pole Butterworth each, bw = Q value in octaves; Q 8.2 = least filtering); modes: Normal (independent L/R, each feeds back into itself), Ping-Pong (input = mono sum into L; L's output feeds R, R's feeds L), Tap->Delay (mono: input → L line once (no feedback) → R line with feedback; both outputs to both channels); delay-time changes slew (read position glides, ≤ 1 ms per ms) |
| Compressor | stereo-linked peak detector (max |L|,|R|) in dB with attack/release one-poles; hard knee; GR = (level − thr)·(1 − 1/ratio) above thr; makeup = `gain` value; MIX; **Limit** (ratio law 1e9): look-ahead = attack `10·n²` ms (0–10), gain = min over the window of `thrAmp/|x|` (≤ 1), release one-pole; `latency` = look-ahead samples. **Multiband**: LR4 crossovers at 128.3 Hz and 2500 Hz; band b threshold amp `thrAmp·mb_b` (mb value 0–2); per band static curve: above T: `T + (in − T)/R`; below `Tl = T − 24 dB` (and above −80 dBFS): `Tl − (Tl − in)/R` (upward, boost ≤ +24 dB); between: unchanged; R = 1 ⇒ identity |
| Reverb Plate | Dattorro plate (1997 topology; delay lengths scaled from 29761 Hz to `base` and by `0.5 + size`), pre-delay `200·t` ms, input LP `20000·0.05^hicut` Hz, input diffusion 0.75/0.625, decay diffusion 0.7/0.5, tank decay `0.2 + 0.78·size`, tank damping one-pole LP at `20000·0.03^damp` (c slot), output HP at `20·50^locut` Hz, width (w slot) scales the side of the wet; tank modulation 0.5 Hz ±8 samples |
| Reverb Hall | 4 input diffusion allpasses (g 0.7) → 8-line FDN (Householder), base lengths `[1009, 1123, 1277, 1361, 1489, 1597, 1733, 1867]` samples @48 kHz × `(0.4 + 1.6·size)` (scaled to base), decay T60 = `0.8 + 11.2·t` s (t ≥ 0.999 → infinite, gain 1), per-line gain `10^(−3·len/(T60·fs))`, in-loop LP `20000·0.05^hicut`, SPIN: delay modulation rate `0.05 + 3·c²` Hz, depth `12·w` samples, output HP `20·50^locut` Hz; outputs L/R = alternating-sign sums of the lines |
| EQ | two RBJ biquads (cookbook), `A = 10^(gain/40)`, `Q = 0.25·40^q`, `w0 = 2πF/fs`, `α = sin w0/(2Q)`; left band: Shelf = low shelf, Peak = peaking, HP = high-pass (gain ignored); right band: Shelf = high shelf, Peak, LP = low-pass; series L → H |
| Filter | `SerumDSP.SFilter` (type `fxp.filType`), cutoff/res/drive/var eff values, pan as §6.11 (no key track), MIX linear wet/dry, then LEVEL |

### 8.6 `graph.js` (E5) — shared curve editors

```js
import { CurveEditor, EnvEditor, pts } from './graph.js';
const ed = new CurveEditor(container, {
  get: () => points,                 // current points ([x,y,c(,mx,my)])
  set: (points, phase) => {},        // phase: 'start' | 'move' | 'end' | 'set'
  grid: () => ({ x, y }),            // snapping grid (0 = free)
  kind: 'lfo' | 'remap' | 'xshape' | 'curve',   // lfo: loop/start markers + point mods; remap/xshape/curve: no markers
  loop: () => idx, setLoop: (idx) => {}, start: () => idx, setStart: (idx) => {},   // lfo only
  playhead: () => phase | null,      // animated marker (rAF while visible)
  busMenu: (pointIdx, axis) => {},   // lfo only: "Modulate X / Y" handler (serum-ui wires it to bus allocation)
  bipolar: false, readOnly: false, height: 160,
});
ed.refresh(); ed.destroy();
```
Gestures (inv A13, normative): double-click empty = add point (snapped if grid), double-click point = delete (not first/last); drag point (Alt = snap to grid; first/last only move in y); drag curve handle (segment midpoint) vertically = curvature (`c`), Alt-drag handle = all handles; Shift-click/drag on background = step-draw at grid x (segment shape from the menu: step, ramp up, ramp down, curve); drag on background = marquee select; Cmd/Ctrl-drag selected = relative "rainbow" move (weight `1/(1 + distance·8)`); Delete/Backspace deletes selection; right-click / long-press menu: Segment shape ▸ (Step, Ramp Up, Ramp Down, Curve), Delete Selected, Set Start Point, Set Loopback Point (lfo), Clear Loopback, Flip Horizontal, Flip Vertical, Modulate X, Modulate Y (lfo), Remove Point Modulations, Load Shape ▸ (factory shapes + user), Save Shape…, Wavetable to LFO Shape (lfo, via callback `fromWavetable`). Shift-Cmd/Ctrl-click a point = set loopback. Keyboard: Tab cycles points, arrows move (Shift = fine), +/− adds/removes.

`EnvEditor(container, { env: () => ({a, h, d, s, r, ca, cd, cr}) /* engine values, s,c 0–1 */, set: (patch, phase) => {}, ghosts: () => [env...], lock: () => bool, zoom: () => seconds, playhead: () => ({stage, t}) | null })` — draws A-H-D-S-R with draggable corner points (time in x on a lock-to-fit or zoomed axis; S in y) and three curve handles (drag; right-click resets to 0.5); emits engine values which serum-ui converts with `lawNorm`.

Pure helpers (`pts` namespace, node-testable): `insert(p, x, y)`, `remove(p, idxs)`, `move(p, i, x, y, {snap, grid})`, `setCurve(p, i, c)`, `stepDraw(p, x0, x1, y, gridX, shape)`, `flipH(p)`, `flipV(p)`, `normalize(p)` — all return new arrays and satisfy §2.3. Factory LFO shapes (`pts.SHAPES`): Triangle, Sine (8 points, c ±0.45), Saw Up, Saw Down, Square, Pulse 25, Ramp Exp, Stairs 4, Stairs 8, Bounce, S&H-ish (16 random steps, seeded), Sidechain (fast dip). User shapes: `localStorage['synth.sx.shapes']` (`[{name, pts}]`), JSON import/export.
