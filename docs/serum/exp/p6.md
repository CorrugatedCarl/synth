### 9.4 Modulation interactions (inv A16)
- **Drag a tile** (pointer moves > 4 px): a ghost label follows; elements with `data-dest` under the pointer get an outline and `cursor: copy`; release on one → `dropRow` (§5.8) → selected source = that tile. Release on a matrix SOURCE/AUX menu → sets that row's source. Release over an LFO graph point (within 8 px) → small menu **X / Y** → `busForPoint` → point `mx`/`my` = bus, row `src → bus<k>` (bipolar, amount 0.5). Escape cancels.
- **Halos** (`setMod`, refreshed on state change and at ≤ 30 fps from snapshots): one arc per row (§5.8); selected source in `--sx-accent`, negative depth in `--sx-neg`, others in `--sx-mute`; live dot at the snapshot eff when it differs from base by > 0.002. A modulated knob also shows a small depth handle at its top-left.
- **Depth**: Alt-drag on the knob or drag the depth handle (vertical, 200 px = 2.0 of amount, Shift fine) edits the row of the selected source on this knob, else the most recently added row. **Shift+Alt-click** toggles that row's TYPE.
- **Right-click / long-press menu** (exact order): `Bypass Modulator: <src>` (checkbox, one per row) · `Remove Modulator: <src>` (one per row) · `Remove All Modulators` · separator · `Reset Control` · `Enter Value…` · separator · `Mod Source ▸` (SRC_MENU labels; picks add a row with drop defaults) · separator · `MIDI Learn` / `MIDI Re-learn (CC n)` / `Remove MIDI CC n` (when `host.midiLearn`) · `Lock` / `Unlock`. On PHASE knobs an extra `New MemTrig phase set` (re-randomises `osc[i].memSet`). Items without rows are omitted, never shown disabled.
- **Tile gestures**: Alt-drag an LFO tile onto another LFO tile = `copyLfo`; Alt-drag an LFO tile onto an oscillator display = render the LFO cycle into a new 1-frame user table (`wt.ptsToFrame`) and select it; drag an LFO tile onto the NOISE panel = `wt.lfoToNoise` → new user noise, selected (inv A10.10, A8, A13).
- **Tooltips**: `<Label>: <value>` plus one line per modulator `<src> <±amount%> <-> or ->`.
- Keyboard parity: every action above is reachable from the focused control's context menu; tiles are buttons (`Enter` selects; `Shift+Enter` opens a "Modulate…" destination picker = `addMod` to the chosen dest).
