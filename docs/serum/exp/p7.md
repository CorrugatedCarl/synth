## 10. Tests (node ≥ 20, `node --test tests/`)

### 10.1 Rules
- One file per owner: `tests/serum-core.test.mjs` (E1), `tests/wt.test.mjs` (E2), `tests/serum-dsp.test.mjs` (E3), `tests/fx-dsp.test.mjs` (E4), `tests/serum-ui.test.mjs` (E5, pure helpers + graph `pts` + headless checks), `tests/fx-ui.test.mjs` (E6, pure helpers). Integrator: `tests/integration.test.mjs`.
- A unit test file imports only its own module(s). Fixtures from other modules (a CP, a wavetable entry) are built inside the test from this spec (e.g. a 40-line `makeCP()` that fills §4.1 with defaults from §3.13). Cross-module consistency is the integrator's file (§10.7).
- Deterministic: fixed seeds; no timers; run time < 60 s per file on a laptop.
- DSP scripts are loaded with `node:vm` (they must not use `instanceof` against typed-array constructors or `Array` — use `ArrayBuffer.isView` / `Array.isArray` — because test arrays come from another realm):
```js
import vm from 'node:vm';
import { readFileSync } from 'node:fs';
export function loadDSP() {
  const ctx = vm.createContext({ console });
  for (const f of ['serum-dsp.js', 'fx-dsp.js']) vm.runInContext(readFileSync(new URL('../' + f, import.meta.url), 'utf8'), ctx, { filename: f });
  return { SerumDSP: ctx.SerumDSP, FXDSP: ctx.FXDSP };
}
export function makeProc(base = 48000, OS = 2) {
  return { base, OS, fs: base * OS, CH: 4 * OS, p: null, bendRaw: 0, wheel: 0, at: 0, bpm: 120,
    songBeat: () => null, held: [], voices: [], sx: null };
}
// render loop: per span of n = 128 base frames: N = n*OS; SerumDSP.begin(proc, N); voices[i].render(L, R, N); SerumDSP.fxMods(proc)
```
- Spectral measurements: Blackman-Harris 4-term window, FFT N = 65536, "alias" = largest bin below `min(20 kHz, 0.45·base)` farther than 10 bins from every harmonic of f0, in dB relative to the fundamental bin.
