
DSP code refers to destinations through `SerumDSP.DIDX` / `FXDSP.FIDX`: frozen objects mapping a constant name to the index above, e.g. `DIDX.A_LEVEL = 0`, `DIDX.B_LEVEL = 17` (osc B = osc A + 17), `DIDX.N_LEVEL = 34`, `DIDX.S_LEVEL = 40`, `DIDX.F_CUTOFF = 42`, `DIDX.E1_ATT = 48` (env e = 48 + 5·(e−1)), `DIDX.L1_RATE = 63` (LFO l = 63 + 4·(l−1)), `DIDX.C1_RATE = 95`, `DIDX.G_PORTA = 97`, `DIDX.G_TUNE = 99`, `DIDX.G_AMP = 100`, `DIDX.G_BENDUP = 101`, `DIDX.BUS1 = 103`; `FIDX.G_MASTER = 0`, `FIDX.HYPER_ON = 1` … (fx idx column). Naming rule: id upper-cased, `.` → `_`, `fx.` prefix dropped, e.g. `fx.dly.timeL` → `FIDX.DLY_TIMEL`. `DIDX` covers idx 0–118, `FIDX` covers fx idx 0–85. These two objects (plus `SIDX` for sources: `SIDX.WHEEL = 1`, `SIDX.ENV1 = 2`, `SIDX.LFO1 = 5`, `SIDX.VELO = 13`, `SIDX.NOTE = 14`, `SIDX.AT = 15`, `SIDX.PAT = 16`, `SIDX.CHAOS1 = 17`, `SIDX.NOISE = 19`, `SIDX.RAND1 = 20`, `SIDX.ALT1 = 22`, `SIDX.MACRO1 = 24`, `SIDX.BEND = 28`, `SIDX.MPEX = 29`, `SIDX.RELVEL = 32`, `SIDX.FIXED = 33`) are the **only** id knowledge the DSP scripts have.

### 4.3 Versioning
- State: `s.v`, `fx.v` (int). `normalizeSerum`/`normalizeFx` migrate any older version step by step and always return the current version; unknown future versions are normalized best-effort (unknown keys dropped).
- Compiled: `CP.ver`, `FXP.ver`. A DSP script that receives a different major version MUST render silence (voices inactive / rack bypassed) and `console.warn` once; it MUST NOT throw.
- Tables: `entry.v = 1` on every `'wt'` entry.
- Additive changes (new DESTS/SOURCES appended) bump the minor only and keep indices.

### 4.4 Curves (`bend`, `evalPts`, `renderPts`) — shared definitions

```
bend(t, k) = |k| < 1e-4 ? t : (1 − e^(−k·t)) / (1 − e^(−k))          t ∈ [0,1]
  k > 0: fast start / slow end (concave);  k < 0: slow start (convex);  bend(0)=0, bend(1)=1, monotone.
evalPts(pts, x):
  x ≤ 0 → pts[0].y;  x ≥ 1 → pts[last].y
  j = largest index with pts[j].x ≤ x            (binary search; equal-x pairs ⇒ the later point wins = vertical step)
  if j = last → pts[last].y
  dx = pts[j+1].x − pts[j].x;  if dx ≤ 1e-9 → pts[j+1].y
  y = pts[j].y + (pts[j+1].y − pts[j].y) · bend((x − pts[j].x)/dx, CURVE_K · pts[j].c)
renderPts(pts, n) → Float32Array(n+1), [j] = evalPts(pts, j/n)
```
Constants: `CURVE_K = 10`, `ENV_K = 10`, `MC_K = 6`, `PORTA_K = 6`, `LFO_N = 1024`, `REMAP_N = 2048`, `XS_N = 1024`, `CURVE_N = 128` (velo/note), `MAX_PTS = 256`, `N_MATRIX = 32`, `N_LFO = 8`, `N_ENV = 3`, `N_MACRO = 4`, `N_BUS = 16`, `FRAME = 2048`, `MAX_FRAMES = 256`. serum-dsp re-implements `bend` and the segment evaluation verbatim (it cannot import); a test compares them.

## 5. Modulation semantics (normative)

### 5.1 Knob space
All modulation happens in normalised space: a destination's eff `n` = `clamp(base + Σ offsets, 0, 1)`; the law (§3.1) is applied **after** summing. Stepped laws (int/enum/bool) round the eff `n` through the law. Modulation never writes back into state.

### 5.2 Row evaluation (identical in serum-dsp voice context, mono context and FX context)

```
s  = SRC[mSrc]                                   // native value: uni ∈ [0,1], bi ∈ [−1,1] (§3.12)
if mK ≠ 0: s = uni ? bend(s, mK) : sign(s)·bend(|s|, mK)
x  = mBi ? 0.5·(uni ? 2s − 1 : s)                // bipolar row: ±amount·range/2 around base (inv A16.1, measured)
         :      s                                // unipolar row: up to amount·range (bi sources keep their sign)
if mAux: a = SRC[mAux]; a = (pol(aux) = bi) ? (a + 1)/2 : a;  a = clamp(a, 0, 1)
         x *= mInv ? (1 − a) : a                 // Default = product, (inv) = 1 − aux (inv A16.3)
offset[mDst] += mAmt · x                         // mAmt = amount·output
```
Example (test): LFO→`a.semi`, amount +1, bipolar, LFO value 1 → offset +0.5 → eff 1.0 → +12 st; value 0 → −12 st (inv A16.1).

### 5.3 Sources: timing
- Per-voice sources are computed once per chunk **before** the matrix (§5.6). Envelopes and LFOs return their value at the chunk start; the voice ramps audio-affecting results across the chunk (§5.4).
- Global sources (`wheel`, `at`, `bend`, `macro*`, `fixed`, Off-mode LFOs, mono chaos) are computed per chunk by `SerumDSP.begin` into `proc.sx.g[src·32 + c]` (c = chunk index within the span) and read by every voice.
- `velo`, `rand1/2`, `alt1/2`, `note` (unless `note.porta`) are sampled at note-on and constant for the voice (`velo` updates on a legato note only if `velo.porta`).

### 5.4 Smoothing
| What | How |
|---|---|
| Base values (`CP.base`, `cont = 1`) | `SerumDSP.begin` keeps per-processor smoothed copies: two cascaded one-poles, τ = 6 ms each, advanced once per span (as engine.js `smStep`); provides `baseA` (span start) and `baseD` (delta over the span). Voices use `baseA + baseD·(c+1)/nCh` for chunk c. A patch arriving while nothing sounds snaps (no glide). Stepped laws jump. |
| Wheel / AT / bend | one-pole τ = 1.5 ms per chunk |
| Macros | one-pole τ = 6 ms per chunk |
| Gains (levels, pans, ENV1×AMP, blend gains, filter mix) | evaluated at chunk boundaries, linearly ramped per sample across the chunk |
| Pitch / phase increments | per chunk (glide and modulation are smooth at 4-base-sample resolution); phase accumulators run per sample |
| Filter coefficients | per chunk (`SFilter.set`) |
| LFO output | optional SMOOTH one-pole (§6.12) |
| FX params | `FXRack`: base n smoothed (one-pole τ = 10 ms per span), mods ramped linearly across the `process` call (§5.5); coefficients recomputed every 16 samples |

### 5.5 Per-voice vs mono evaluation and the FX path
- **Voice context**: each active voice evaluates all active rows with `mFx = 0` every chunk into its own offset vector (Float64Array(119)).
- **Most recent voice**: `proc.sx.recent` = the voice that received the latest `noteOn` (set inside `noteOn`). It stays the reference after release/until another note starts (its per-voice source values then freeze at their last values).
- **Mono source vector** `proc.sx.monoSrc` (Float64Array(34)): at the end of every span the recent voice copies its last-chunk per-voice source values into it; global sources are filled by `begin`.
- **Mono context** (`begin`, once per span, using the previous span's `monoSrc`): evaluates rows whose destination scope is `V*M` (LFO rates/smooth for Off-mode LFOs, chaos rates for mono chaos) → `proc.sx.monoEff` (Float64Array(119)); it also serves the UI snapshot (§8.4.4).
- **FX context** (`SerumDSP.fxMods(proc)`, after the voices, current span's `monoSrc`): evaluates rows with `mFx = 1` → returns a reused `Float64Array(86)` of **offsets** (fx idx order). The engine passes it to `FXRack.setMods(arr)`. Non-Serum tracks never call `setMods` (offsets stay 0).
- FX modulation from per-voice sources therefore follows the most recently triggered note (inv A16.5 / A20.1).

### 5.6 Order inside one voice chunk (normative; breaks every feedback cycle)
1. Advance envelopes and LFO/chaos phases using the **previous chunk's** eff values of their own destinations (`V*`: env times, LFO rate/rise/delay/smooth, chaos rate, bus values for point links).
2. Compute the voice's per-voice sources; read the global ones for chunk c.
3. Evaluate voice rows → eff[0…118].
4. Derive engine values (pitch, levels, warp, filter …) for the chunk end; ramp from the previous values across the chunk.
5. Render CH samples.
The first chunk after `noteOn` uses the base values for step 1.

### 5.7 LFO point modulation (inv A13)
A point with `my = b` uses `y' = clamp(y + vb, 0, 1)`; with `mx = b`: `x' = clamp(x + vb, x_prev, x_next)` (neighbours' unmodulated x), where `vb` = engine value of `bus<b>` (lin −1…1; base always 0.5 → 0). An LFO with `lfoPmAny = 1` is evaluated with `evalPts` on the modified point list (per chunk, per voice — or once per chunk in `begin` for Off mode with the mono bus values); otherwise via `lfoTab` (linear interpolation between the 1025 samples).

### 5.8 Drag-and-drop defaults and halo maths (UI, `serum-core` helpers)
- Drop polarity: `bi = DESTS[dst].ctr ? 1 : 0`. Drop amount: bipolar 0.5; unipolar `max(0.05, min(0.5, 1 − base))` ("limit depth on drop" behaviour). Row goes to the first inactive slot (`src === ''`); none free → no-op + notice "Matrix full (32 slots)".
- Halo arc of a row on its knob (normalised, clamped to [0,1]): unipolar `[base, base + mAmt]` (ordered); bipolar `[base − |mAmt|/2, base + |mAmt|/2]`. Colour: `sel` if the row's source is the selected source, `neg` if `amt·out < 0`, otherwise `other`. Live indicator = snapshot eff (§8.4.4).

## 6. Voice behaviour (serum-dsp, normative)

### 6.1 Note-on (`noteOn(n, vel01, legato, glc)`; `glc` ignored)
| Situation | Behaviour |
|---|---|
| fresh (voice inactive) | envelopes start from 0 (attack), Trig/Env LFOs restart at `lfoStart`, Off LFOs untouched, chaos (per-voice) reseeded randomly, `rand1/2` drawn, `alt` taken from the processor flip-flop, unison count `N = law(eff uni)` sampled, Random-mode detunes drawn, oscillator phases initialised (§6.4), noise read position initialised, sub phase = 0, filter state cleared, `proc.sx.recent = this` |
| steal (voice active, `legato = false`) | as fresh **except**: envelopes restart from their current level (no jump), filter state kept, and oscillator phases are **not** reset unless `CP.legato` (poly legato) is on (inv A3: S1 steal behaviour) |
| legato (`legato = true`: engine mono legato with an overlapping key) | no envelope/LFO retrigger, phases continue, pitch glides if porta > 0 else jumps; `velo` re-captured only if `veloPorta` |
| portamento | applies when porta time > 0 and (`always` or overlapping: `legato` arg, or mono with `proc.held.length > 1`, or poly with another voice `gate`); start pitch = `proc.sx.lastPitch` (current pitch of the previous recent voice, before this note). Duration T = time (`scaled`: × |Δst|/12). Progress `p(τ) = bend(τ/T, PORTA_K·c)`, c = eff `g.curve` value; pitch = start + (target − start)·p |
| pitch tracking off | the oscillator's note is MIDI 0 (8.18 Hz at A4 = 440) instead of `n` (glide still applies to the note-relative offsets) |

### 6.2 Note-off (`noteOff(rv)`), kill
`noteOff`: `gate = false`; envelopes enter release from their current level; Env-mode LFOs leave their loop and run to the end; `relvel = rv ?? 0.5`. `kill()`: every state cleared, `active = false` (no fade; the engine renders its de-click tail beforehand). A voice becomes inactive when not gated and ENV 1 ≤ 1e-5 (−100 dB).

### 6.3 Pitch
Per oscillator o, unison voice i (semitones, MIDI scale):
`P = note' + 12·oct + semi + fine/100 + crs + stack_i + detune_i + bendSt + tune` where `note'` = gliding note (or 0 when tracking off), `bendSt = bend ≥ 0 ? bend·bendUp : −bend·bendDn` (bend = smoothed `proc.bendRaw`, bendUp/Dn = eff `g.bendup`/`g.benddn` values), `tune` = eff `g.tune` value. `f = a4 · 2^((P − 69)/12)`, clamped to [0.01 Hz, 0.45·fs·r].
Sub: `P_sub = note' + 12·subOct + bendSt + tune` (no fine/semi). Noise: §6.8.

### 6.4 Phase (OSC A/B; inv A3)
Let `ph` = eff `phase` n, `rd` = eff `rand` value, `u_i` uniform [0,1) per unison voice per note.
| Base PHASE | RAND | Start phase of unison voice i |
|---|---|---|
| base n < 0.9995 | any | `frac(φ0 + rd·u_i)` with φ0 = 0 and the knob acting as a continuous offset (below) |
| base n ≥ 0.9995 (Mem) | base < 0.9995 | `frac(proc.sx.memPh[o] + memSet[o·16+i])` — continues the previous note (`memPh[o]` = running phase of the recent voice's unison voice 0, updated per chunk) |
| Mem | base ≥ 0.9995 (MemTrig) | `memSet[o·16+i]` exactly (repeatable; inv A3 MemTrig) |
Read phase = accumulator + `min(ph, 0.99999)` (the PHASE knob is a continuous phase offset in cycles, so modulating it phase-modulates; in Mem modes the offset is 0).

### 6.5 Wavetable read
- Table entry from `SerumDSP.tables.get(CP.wt[o])` (re-fetched when the id changes or `storeWT` replaces it — compare a `gen` counter on the entry). Missing entry ⇒ that oscillator contributes 0 (no throw).
- Frame: discrete (`entry.interp = 0`): `k = min(F−1, floor(pos·F))`; interpolating (`interp = 1`): `pos·(F−1)`, linear blend of two frames. `pos` = eff `wt` value + unison offset, clamped. When the discrete frame changes, the voice crossfades old → new frame linearly over one chunk.
- Mip level per §7.4 with `speed` from §3.3; when the level changes the voice crossfades old → new level over one chunk.
- Sample read: 4-point cubic Hermite (Catmull-Rom) on the level's `len` (power of two, wrap with mask): `c1 = ½(x₁−x₋₁)`, `c2 = x₋₁ − 2.5x₀ + 2x₁ − ½x₂`, `c3 = ½(x₂−x₋₁) + 1.5(x₀−x₁)`, `y = ((c3·f + c2)·f + c1)·f + x₀`.

### 6.6 Unison mix
For osc o with N voices: `L_o = Σ_i g_i·cL_i·x_i`, `R_o = Σ_i g_i·cR_i·x_i`, then × `1/√(Σg²)`; `cL = √2·cos((p+1)π/4)`, `cR = √2·sin((p+1)π/4)`, p = pan position (§3.8). Then × LEVEL (`pow2` value) and PAN balance with the same equal-power law (p = eff pan value). Sub: mono × level (linear) × pan. Noise: stereo × level (`pow2`) × pan balance.

### 6.7 Warp evaluation
- Warp amount per unison voice `w_i = clamp(eff warp + t_i·uniwarp·0.5, 0, 1)` (eff values).
- FM/AM/RM from the other oscillator: the modulator is the other osc's unison voice `i mod N_other`, raw (post its own warp, pre level/pan), **same sample**; the modulator osc is rendered first. The FM source must be `on`; at most one direction (normalize guarantees). FM (Noise): mono average of the noise raw output; FM (Sub): sub raw output.
- Remap modes use `CP.remap` with linear interpolation at `p·2048`.

### 6.8 Noise oscillator (inv A8)
Entry (§7.9) at its own `rate`. Read increment per OS sample: `inc = (rate/fs)·2^((pitchSt + fine/100 + key + bendSt·key01)/12)`, with `pitchSt` = eff `n.pitch` value (keytrack on: `round` to semitones), `key = noiseKey ? (note' − root) : 0`, fine = eff `n.fine` value (applies only with keytrack on — inv A19 "fine-tunes keytracked noise"), bend applies only when keytracked. Start position at note-on = `(phase + rand·u)·len` (phase/rand eff values); PHASE also acts as a continuous position offset (scratch). Loop: when `!noiseOneshot`, wrap inside `[loopStart, loopEnd)` (whole file if absent); one-shot: output 0 after the end. 4-point Hermite interpolation; mono files feed both channels.

### 6.9 Oversampling (inv A3/A19)
`r = max(1, CP.os / proc.OS)` ∈ {1, 2, 4}. When r > 1 and any enabled oscillator has warp ≠ 0, the voice renders its whole oscillator section (A, B, sub, noise) at `fs·r` and decimates each of the three mixes (filter input, dry, direct; stereo) back to `fs` with half-band FIRs (127-tap Kaiser β = 10 for the last stage, 35-tap β = 9 for an earlier one — the engine's design). Otherwise the oscillators run at `fs` (the host's OS ≥ Serum's OS already gives the warp at least the requested rate). Mip-level selection uses the rate the oscillator actually runs at.

### 6.10 Envelopes (ENV 1–3; inv A12)
AHDSR, value ∈ [0,1], ticked once per chunk (dt = CH/fs), times from eff values (one-chunk lag). Stage progress `q` advances by dt/T (T = 0 ⇒ immediate). Attack: `v = v0 + (1 − v0)·bend(q, kA)` (v0 = level at trigger); Hold: 1; Decay: `v = 1 + (S − 1)·bend(q, kD)`; Sustain: `v = S` (follows S modulation); Release: `v = vR·(1 − bend(q, kR))` (vR = level at release). `kA, kD, kR` from `CP.envK`. ENV 1's S is the `pow2` value (amplitude), ENV 2/3 linear. ENV 1 multiplies every source (ramped per sample); ENV 2/3 are sources only.

### 6.11 Filter (SFilter; inv A11)
- Cutoff Hz per channel: `fcL = fc·2^(+(0.5 − pan)·3)`, `fcR = fc·2^(−(0.5 − pan)·3)` (pan = eff `f.pan` n; ±1.5 octaves at the extremes; left of centre raises L). Key track: × `2^((note' − 60)/12)`. Clamp [8 Hz, 0.45·fs].
- Drive: input gain `10^(16·√drive / 20)` (≈ +8 dB at 25 %, +16 dB at 100 %, inv A11.1) into the family's nonlinearity (families without one apply soft `tanh` only above |x| > 1).
- Res ∈ [0,1], Var ∈ [0,1] per family (§3.4). EQ family gain law: `dB = var < 0.5 ? max(−96, 40·log10(2·var)) : 48·(var − 0.5)` (0 → −96 dB, 0.5 → 0 dB, 1 → +24 dB).
- Mix: `out = (1 − mix)·dry + mix·wet` (linear).
- Level calibration: with res 0, drive 0, every LP/HP/BP/EQ family has passband gain 1 ± 1 dB (BP: peak gain 1).

### 6.12 LFOs (inv A13)
- Phase φ ∈ [0,1). Rate: BPM off → Hz = eff `lN.rate` value; BPM on → ladder entry (§3.9) at the current `proc.bpm`.
- **Trig**: φ = `lfoStart` at note-on (not on legato), then advances. **Env**: like Trig but stops at φ = 1 (holds `y(1)`); with `lfoLoop ≥ 0` and `gate`, wraps from 1 to `lfoLoop`. **Off**: one shared phase per processor (in `begin`); BPM + Anchor and transport playing (`proc.songBeat()` ≠ null): `φ = frac(lfoStart + beat/beats)`; BPM + Anchor while stopped: `φ` advances from a processor beat clock at `proc.bpm`; otherwise free-running accumulation.
- **Anchor** in Trig/Env + BPM: `φ = frac(lfoStart + (beatNow − beatAtTrigger)/beats)` (jumps on rate change); Anchor off: accumulate increments (no jumps).
- Raw value `y = lfoTab` (or point-modulated `evalPts`). Delay/Rise (per voice, also for Off-mode LFOs, measured from note-on): during DELAY `out = y0` (first point's y); during RISE `out = y0 + (y − y0)·(τ/rise)`; then `out = y`. DELAY/RISE seconds = eff value (0–4 s); BPM on: × `120/proc.bpm` (tempo-relative; display in beats).
- SMOOTH: one-pole on `out`, τ = `0.5·smooth³` s (0 = off), per voice (Off mode: applied to the shared raw value before delay/rise).

### 6.13 Chaos 1 / 2 (inv A14)
- Chaos 1 = Rössler x (a = 0.2, b = 0.2, c = 5.7), output `clamp(x/12, −1, 1)`; Chaos 2 = Lorenz x (σ = 10, ρ = 28, β = 8/3), output `clamp(x/20, −1, 1)`. RK2 integration once per chunk with `dt_sys = rateHz·T0·CH/fs` (T0 = 6.07 for Rössler, 0.75 for Lorenz) and at most 0.02 per sub-step (sub-step as needed).
- BPM on: rate snaps to the nearest straight `LFO_LADDER` entry (log distance) at `proc.bpm`.
- S&H on: output holds and updates once per `1/rate` seconds. Mono on: one generator in `begin` (global source); off: one per voice, initial state randomised at note-on (x, y, z ~ uniform ±1 offset from (1, 1, 1)).

### 6.14 Voice counter (inv A17)
`snapshot.oscVoices` = Σ over active voices of (A on ? N_A : 0) + (B on ? N_B : 0) + sub on + noise on; `snapshot.maxVoices` = `poly · (16·oscOnA + 16·oscOnB + subOn + noiseOn)`.
