# SPEC-serum — Serum-style instrument + FX rack: implementation contract (v1)

Binding contract for six engineers working in parallel (E1–E6) and the later integrator. Read §0 completely before anything else. Every table here is normative unless a row is marked **IMPL-free** (engineer's choice within the stated constraints).

- Precedence: **this spec** > `ARCH.md` (only where §0.3 says so) > `serum-inventory.md` (feature authority; cited as "inv A3", "inv A20.4.6", …). Part A of the inventory is in scope except the ARCH.md exclusions (preset-browser extras, skins/zoom/resize, MIDI CC map files, drag-export, default.fxp, MPE behaviour, tuning files).
- Where Serum's maths is unpublished the formulas below are **normative for this project** (marked IMPL in the inventory). Do not "improve" them silently — tests on both sides of every interface depend on them.
- MUST / SHOULD / MAY carry their usual meaning.

### 0.2 Code rules (all files)
- Site style: 2-space indent, semicolons, single quotes, `'use strict';` at the top of classic scripts, no dependencies, no build step, ES2020.
- No `eval`, `new Function`, `with`, string-to-code of any kind (the formula parser is an AST interpreter).
- **Environment neutrality of the DSP scripts**: `serum-dsp.js` and `fx-dsp.js` MUST NOT reference `sampleRate`, `currentTime`, `currentFrame`, `registerProcessor`, `AudioWorkletProcessor`, `window`, `document`, `self` anywhere. All rates arrive through constructor/`proc` arguments. They are loaded in three places: the AudioWorkletGlobalScope (`addModule` before `engine.js`), the main thread (`<script>` injected by `loadDSP`, §8.8) and node `vm` contexts (tests). Each script attaches exactly one global (`SerumDSP` / `FXDSP`) and is idempotent if evaluated twice (second evaluation replaces the object; the wavetable `Map` MUST survive: `globalThis.SerumDSP && globalThis.SerumDSP.tables || new Map()`).
- DSP hot paths: all state in `Float64Array`s or numeric fields initialised in constructors (monomorphic shapes); no allocation per sample/chunk/span (allocate in constructors, `apply()`, `set()`, `storeWT`); no closures, `arguments`, destructuring, `try`, `Array.prototype.forEach/map` inside render loops; feedback states flushed: `if (Math.abs(s) < 1e-30) s = 0` at least once per span per state.
- Main-thread pure modules: functions MUST NOT mutate their inputs unless the doc says "in place".

### 0.3 Deviations from ARCH.md (decided here, binding for the integrator)
1. **`patch.fxr`, not `patch.fx`.** The engine's existing `p.fx` (`FxP`: chorus/ensemble/hiss of the analog models) would collide. The compiled FX rack for every track travels as `patch.fxr` (§4.2).
2. **Direct-out bus.** Sub/Noise DIRECT OUT bypass filter *and* FX (inv A1, A7, A8). Voice signature becomes `render(bufL, bufR, N, dirL, dirR)`; `dirL/dirR` are a second OS-rate stereo pair supplied when `patch.serum.direct === 1` (else `undefined`; voices then mix direct sources into `bufL/bufR` after the filter). The engine decimates the pair and passes it to `FXRack.process(L, R, n, dL, dR)`.
3. **Master volume is post-FX** (inv A1, A18): it is FX-segment destination 0 (`g.master`), applied by the rack's output stage. `compileFx(fx, { master })` receives Serum's master `n`; non-Serum tracks pass nothing (gain 1).
4. **Table transport** carries a `kind` (`'wt'` | `'noise'`). Sub shapes and noise sources travel through the same `{t:'wt'}` message (ids `sub:*`, `noise:*`, `nzuser:*`). Extra messages: main→worklet `{t:'wtf'}` (replace one frame), `{t:'wtdel'}`, `{t:'smon', on}`; worklet→main `{t:'smon', …}` snapshots (§11).
5. **FXRack** gains `trigger()`, `idle()`, `monitor()`, `phases()` (§8.5).
6. **Widget kit** (knob, menu, toggle, number box, slider, context menu, CSS injection) lives in `fx-ui.js`; `graph.js` curve editors are used by `fx-ui.js` for the X-Shaper.
7. **DSP scripts run on the main thread too** (UI displays use the real code: filter response, warp preview, Render OSC Warp, distortion transfer curve, EQ/delay-filter curves).
8. **Poly AT** mirrors channel aftertouch (host has no poly AT). **MPE X/Y/Z** keep their source slots but read 0 (MPE excluded). **Release velocity** = 0.5 unless the host passes one to `noteOff(rv)`.

## 1. Signal flow (normative)

Per **voice** (all stereo, OS rate):

```
                       ┌── routed (filter.route[A,B,N,S] = 1 and filter.on) ──► FILTER (SFilter, stereo) ──► wet/dry by f.mix ──┐
OSC A ─ unison sum ─┐  │                                                                                                         │
OSC B ─ unison sum ─┼──┤                                                                                                         ├─► × ENV1 × AMP ─► bufL/bufR (main bus)
SUB  (mono→pan) ────┤  └── not routed (or filter off), and not direct ────────────────────────────────────────────────────────────┘
NOISE (stereo) ─────┘
SUB / NOISE with DIRECT OUT on ─────────────────────────────────────────────────────────────────────────────────► × ENV1 × AMP ─► dirL/dirR (direct bus)
```

- Each source is multiplied by its LEVEL law and PAN (balance) **before** routing. ENV 1 is hard-wired to the amplitude of every source (inv A1) and is applied **after** the filter (so filter resonance rings with the note and dies with ENV 1).
- FILTER off ⇒ routed sources go to the dry path unchanged.
- A DIRECT source never enters the filter, even if its route button is on (inv A7: "if off and S routed, sub is filtered").
- Per **processor**: Σ voices main bus → decimate (engine) → `FXRack.process` (modules in user order, §8.5) → + decimated direct bus → × master (`g.master`) → engine DC block / limiter.

## 2. Serum state schema — `defaultSerum()`

Stored at `track.vals.s`; presets are `{ name, v: { s }, fx? }`. Plain JSON (no typed arrays, no `undefined`, no `NaN`). Typical size < 24 KB; MUST stay < 64 KB (user wavetables are referenced by id, never embedded here).

### 2.3 Points (graphs)
A graph is an array of points `[x, y, c]` or `[x, y, c, mx, my]`:

| Field | Range | Meaning |
|---|---|---|
| `x` | [0,1], non-decreasing; first point x = 0, last point x = 1 | position (equal x allowed = vertical step) |
| `y` | [0,1] | value (LFO: 0 bottom, 1 top; remap: output phase; velo/note: output) |
| `c` | [−1,1] | curvature of the segment from this point to the next (`bend(t, CURVE_K·c)`, §4.4) |
| `mx`, `my` | int 0–16 | LFO graphs only: link the point's X / Y to LFO bus 1–16 (0 = none). Omitted when both 0. First/last point `mx` is always 0. |

Limits: 2 ≤ length ≤ `MAX_PTS` (256). `normalizeSerum` sorts by x (stable), clamps, forces end x values, drops extra points beyond 256.

### 3.3 Warp modes (`WARPS`)

`speed` = factor applied to the read frequency for mip-level selection (§7.4); `w` = effective warp amount ∈ [0,1] (WARP eff ± unison warp offset, clamped). `x(φ)` = table read at phase φ ∈ [0,1). Formulas are normative (IMPL).

| idx | id | name (OSC A / OSC B) | phase / output transform | `speed` |
|---|---|---|---|---|
| 0 | `off` | Off | φ | 1 |
| 1 | `sync` | Sync | `r = 2^(4.4·w)`; read `x(frac(φ·r))` | r |
| 2 | `sync_half` | Sync 1/2 Win. | sync, output × (`φ<0.25 \|\| φ>0.75 ? sin²(2πφ) : 1`) | r |
| 3 | `sync_win` | Sync Window | sync, output × `sin²(πφ)` | r |
| 4 | `bend_p` | Bend + | per half: `u = φ<.5 ? 2φ : 2−2φ`, `u' = u^K`, `K = 2^(2.5·w)`; `φ' = φ<.5 ? u'/2 : 1−u'/2` | max(K, 1/K) |
| 5 | `bend_n` | Bend − | as Bend + with `K = 2^(−2.5·w)` | max(K, 1/K) |
| 6 | `bend_pn` | Bend +/- | as Bend + with `K = 2^(2.5·(2w−1))` | max(K, 1/K) |
| 7 | `pwm` | PWM | `φ' = min(1−2⁻²⁴, φ/(1 − 0.995·w))` (remainder holds the end value) | 1/(1−0.995w) |
| 8 | `asym_p` | Asym + | `φ' = φ^K`, `K = 2^(2.5·w)` | max(K, 1/K) |
| 9 | `asym_n` | Asym − | `K = 2^(−2.5·w)` | max(K, 1/K) |
| 10 | `asym_pn` | Asym +/- | `K = 2^(2.5·(2w−1))` | max(K, 1/K) |
| 11 | `flip` | Flip | output = `φ < w ? x(φ) : −x(φ)` | 1 |
| 12 | `mirror` | Mirror | `q = φ<.5 ? 2φ : 2−2φ`; `φ' = q^K`, `K = 2^(2.5·(2w−1))` | 2·max(K, 1/K) |
| 13 | `remap1` | Remap 1 | `φ' = φ + w·(G(φ) − φ)` | 2 |
| 14 | `remap2` | Remap 2 | `q = φ<.5 ? G(2φ)/2 : 1 − G(2−2φ)/2`; `φ' = φ + w·(q−φ)` | 2 |
| 15 | `remap3` | Remap 3 | `φ' = frac(φ − (0.9·w/2π)·sin(2πφ))` (sinusoidal, graph unused) | 1 + 0.9w |
| 16 | `remap4` | Remap 4 | `s = floor(4φ)`, `u = 4φ−s`, `u' = s odd ? 1−G(1−u) : G(u)`, `q = (s+u')/4`; `φ' = φ + w·(q−φ)` | 4 |
| 17 | `quantize` | Quantize | `M = max(2, round(2048·2^(−10w)))`; `φ' = floor(φ·M)/M` | 1 |
| 18 | `fm_osc` | FM (from B) / FM (from A) | phase modulation: `φ' = frac(φ + I·m)`, `I = 3·w^1.5`, `m` = other osc (§6.7) | 1 + 6.3·I |
| 19 | `am_osc` | AM (from B) / AM (from A) | output `x·(1 − w + w·(0.5 + 0.5·m))` | 1 |
| 20 | `rm_osc` | RM (from B) / RM (from A) | output `x + w·(x·m − x)` | 1 |
| 21 | `fm_noise` | FM (Noise) | as 18 with `m` = noise osc raw output (mono avg) | 1 + 6.3·I |
| 22 | `fm_sub` | FM (Sub) | as 18 with `m` = sub osc raw output, `I = 4·w^1.5` | 1 + 6.3·I |
| (23) | — | (empty slot, never used) | | |

`G(p)` = the oscillator's remap graph evaluated through `remapTab` (§4.1). Modes 18–22 require the modulator source to be **on** (its LEVEL may be 0); otherwise `m = 0`. 2D display shows the warp for all modes except 18–22 (inv A5).

### 3.4 Filter types (`FILTERS`, `FILTER_CATS = ['Normal','Multi','Flanges','Misc']`)

`f_var` (filters whose Var is a frequency: L6/H6 LP/HP FREQ, dual FREQ, Scream) = `8.1758·(22050/8.1758)^var` Hz. `w` (HL WID) = `0.25 + 5·var` octaves. Families are SFilter implementation classes (§6.11); recipe hints are normative where tests check them (§10.4) and IMPL-free otherwise.
